## 🌟 मुख्य विशेषताएं (Key Features)

### 1. 👑 Royal Rajasthani Theme & Design
* **रॉयल कलर कॉम्बिनेशन**: Maroon (`#7B001C`), Imperial Gold (`#D4AF37`), Royal Cream (`#FDFBF7`), Charcoal Black (`#1A1A1A`)।
* **पारंपरिक मोटिफ**: राजस्थानी झरोखा, गोटा-पत्ती और रॉयल आर्चेस।
* **100% रिस्पॉन्सिव**: मोबाइल, टैबलेट और डेस्कटॉप पर स्मूथ अनुभव। मोबाइल के लिए Bottom Navigation Bar।

### 2. 🛍️ Customer Storefront (ग्राहक वेबसाइट)
* **होमपेज**: रॉयल हीरो बैनर, फीचर्ड कलेक्शंस, कैटेगरी ग्रिड, बेस्ट सेलर्स, न्यू अराइवल्स, कस्टमर रिव्यूज, स्टोर लोकेशन व फुटर।
* **प्रोडक्ट कैटलॉग व फ़िल्टर**: श्रेणी (Category), प्राइस स्लाइडर, साइज़ (S, M, L, XL, XXL, Free Size), कलर और इन-स्टॉक फ़िल्टर।
* **प्रोडक्ट डिटेल**: मल्टी-इमेज गैलरी, रियल-टाइम स्टॉक इंडिकेटर, साइज़ व कलर सेलेक्टर, ऐड टू कार्ट और बाई नाउ।
* **Order on WhatsApp**: हर प्रोडक्ट पर डायरेक्ट बटन जो प्रॉडक्ट का नाम, SKU, साइज़ और कीमत के साथ WhatsApp चैट खोलता है।
* **डायनामिक कार्ट व चेकआउट**: मुफ़्त डिलीवरी प्रोग्रेस बार, कूपन डिस्काउंट, कैश ऑन डिलीवरी (COD) और ऑनलाइन UPI QR कोड पेमेंट।
* **ऑर्डर ट्रैकिंग**: स्टेटस स्टेपर (`Pending` → `Confirmed` → `Processing` → `Shipped` → `Delivered`)।
* **कस्टमर अकाउंट**: रजिस्ट्रेशन, लॉगिन और प्रोफ़ाइल।

### 3. 💼 Store ERP & Business Management (एडमिन पैनल)
* **डैशबोर्ड**: कुल बिक्री (Sales), कुल खरीद (Purchases), कुल स्टॉक वैल्यू, ग्राहक बकाया (Customer Outstanding), सप्लायर बकाया (Supplier Due), पेंडिंग ऑर्डर्स और चार्ट्स (Monthly Sales Bar & Category Doughnut)।
* **POS काउंटर बिलिंग**: दुकान पर आने वाले ग्राहकों के लिए तेज़ बिलिंग। बारकोड/SKU से सर्च, डिस्काउंट, GST, उधारी और स्टॉक का ऑटोमैटिक डिडक्शन।
* **परचेज़ मैनेजमेंट**: सप्लायर से माल खरीदना, ऑटोमैटिक स्टॉक वृद्धि और सप्लायर लेज़र अपडेट।
* **स्टॉक ऑडिट व इन्वेंट्री**: करंट स्टॉक, लो-स्टॉक अलर्ट्स, स्टॉक इन/आउट मैन्युअल एडजस्टमेंट और ऑडिट हिस्ट्री लॉग।
* **कस्टमर CRM व लेज़र**: सभी ग्राहकों का पूरा हिसाब-किताब, लेन-देन और पेमेंट रसीद वाउचर।
* **सप्लायर CRM व लेज़र**: सभी सप्लायर्स का पूरा हिसाब-किताब, परचेज़ हिस्ट्री और पेमेंट वाउचर।
* **GST टैक्स इनवॉइस**: दुकान के लोगो, GSTIN, HSN कोड्स और UPI QR कोड के साथ प्रिंटेबल A4 इनवॉइस।
* **रिपोर्ट्स**: दैनिक/मासिक सेल्स, परचेज़, स्टॉक वैल्यूएशन और प्रॉफिट-लॉस रिपोर्ट (एक्सेल/CSV एक्सपोर्ट)।
* **स्टोर सेटिंग्स**: दुकान का नाम, पता, फ़ोन, WhatsApp नंबर, GSTIN, टैक्स दर व डिलीवरी चार्ज अपडेट करने की सुविधा।

## 🚀 वेबसाइट चालू कैसे करें (How to Run)

### विकल्प 1: Windows पर 1-Click Launch (सबसे आसान)
प्रोजेक्ट फोल्डर में मौजूद **`start.bat`** फ़ाइल पर डबल-क्लिक करें। सर्वर तुरंत चालू हो जाएगा!

### विकल्प 2: Terminal / Command Prompt द्वारा
```bash
# 1. प्रोजेक्ट डायरेक्टरी में जाएं
cd "c:\Users\REWANSH COMPUTER\Desktop\MyWebsite"

# 2. सर्वर शुरू करें
node server.js
```

वेबसाइट के यूआरएल:
* **ग्राहक वेबसाइट (Customer Storefront)**: [http://localhost:3000](http://localhost:3000)
* **एडमिन पैनल (Admin ERP & POS)**: [http://localhost:3000/admin](http://localhost:3000/admin)

## 🌐 डोमेन और होस्टिंग पर कैसे डिप्लॉय करें (Hosting & Production Deployment)

यह प्रोजेक्ट Node.js और इनबिल्ट SQLite पर आधारित है, इसलिए इसे किसी भी होस्टिंग (cPanel, Linux VPS, Render, Railway, AWS EC2, DigitalOcean) पर बिना किसी झंझट के डिप्लॉय किया जा सकता है।

### A. Linux VPS (Ubuntu / Debian + Nginx + PM2)
```bash
# 1. कोड सर्वर पर कॉपी करें
git clone <your-repo> /var/www/rajputi-store
cd /var/www/rajputi-store

# 2. PM2 प्रोसेस मैनेजर से हमेशा चालू रखें
npm install -g pm2
pm2 start server.js --name "rajputi-store"
pm2 startup
pm2 save

# 3. Nginx Reverse Proxy सेट करें
# /etc/nginx/sites-available/rajputi
# proxy_pass http://127.0.0.1:3000;
```

### B. cPanel Shared Hosting (Node.js App Selector)
1. cPanel में **"Setup Node.js App"** पर क्लिक करें।
2. Application root में अपनी डायरेक्टरी चुनें।
3. Application startup file में `server.js` दर्ज करें।
4. **"Run"** पर क्लिक करें। आपकी वेबसाइट लाइव हो जाएगी!

### C. Cloud Platforms (Render / Railway / Docker)
* **Build Command**: (Blank या `npm install`)
* **Start Command**: `node server.js`
* **Port**: `3000` (या पर्यावरण वेरिएबल `$PORT`)

## ⚡ स्वचालित बिज़नेस लॉजिक (Automatic Business Logic)
1. **बिक्री (Sale) होने पर**: तुरंत इन्वेंट्री से स्टॉक कम होता है और `inventory_logs` में रिकॉर्ड होता है। यदि सेल उधार है तो कस्टमर का आउटस्टैंडिंग बैलेंस बढ़ जाता है।
2. **खरीद (Purchase) होने पर**: तुरंत इन्वेंट्री में स्टॉक बढ़ता है और सप्लायर का आउटस्टैंडिंग बैलेंस अपडेट होता है।
3. **ऑर्डर कैंसिल होने पर**: स्टॉक ऑटोमैटिकली रीस्टोर होकर इन्वेंट्री में वापस जुड़ जाता है।
4. **पेमेंट दर्ज होने पर**: कस्टमर या सप्लायर का बकाया बैलेंस स्वतः कम हो जाता है।

## 📱 WhatsApp व पेमेंट गेटवे इंटीग्रेशन नोट्स
* **WhatsApp**: `settings` में दिए गए नंबर पर डायरेक्ट WhatsApp API लिंक कार्य करता है।
* **UPI**: डायनामिक UPI intent लिंक और QR कोड किसी भी UPI ऐप (GPay, PhonePe, Paytm, BHIM) के साथ तुरंत काम करता है।
* **पेमेंट गेटवे (Razorpay / Cashfree)**: `services/salesService.js` और `public/js/store.js` में Razorpay Checkout स्क्रिप्ट को 10 लाइनों में सीधे कनेक्ट करने के लिए स्ट्रक्चर तैयार है।
